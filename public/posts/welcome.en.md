# Welcome to the blog

This is a space where I'll write about what I'm building and what I'm learning.

## What I'm working on

I'm a second-year IT Systems Development student at Tallinn University of Technology. Most of my time is split between coursework and side projects — recently a full-stack e-commerce app with an ASP.NET Core backend and a Vue 3 SPA frontend.

## Why a blog

Writing forces clarity. If I can explain a concept in plain language, I probably understand it. If I can't, that's a signal to dig deeper.

## The stack behind this site

- **Angular 21** with SSR and prerendering
- **Transloco** for runtime EN/ET language switching
- **Marked** for rendering markdown posts
- Plain CSS with custom properties for theming
